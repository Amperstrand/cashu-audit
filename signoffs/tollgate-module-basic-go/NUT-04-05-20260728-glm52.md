## 2. Findings

### Finding 1: Fragile Spent Token Detection (WARN)
- **Severity**: MEDIUM
- **Location**: tollwallet.go:139
- **Description**: Spent token detection uses `strings.Contains(err.Error(), "Token already spent")` instead of a typed error. The comment acknowledges this: "The upstream cashu library does not export a typed error for 'token already spent', so we match on the error string."
- **Risk**: If gonuts changes the error message wording, spent detection silently breaks — users could double-spend or get incorrect error codes.
- **Recommendation**: File issue on gonuts-tollgate to export a typed error. Short-term: test the exact error string in CI.

### Finding 2: Untrusted Mint Swap Logic (INFO)
- **Severity**: INFO
- **Location**: tollwallet.go:117-145
- **Description**: When `allowAndSwapUntrustedMints=true`, tokens from untrusted mints are swapped to the trusted mint before being credited. This is a TollGate extension not defined in any NUT.
- **Spec compliance**: N/A — NUT-00 allows tokens from multiple mints; swap behavior is implementation-defined.
- **Note**: The swap introduces an additional mint round-trip (receive from untrusted → swap → credit). This could fail if either mint is unreachable.
