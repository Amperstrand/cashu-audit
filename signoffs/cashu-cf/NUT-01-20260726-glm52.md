## Findings

### Finding 1: `src/api/keys.ts` is dead code with incomplete response schema (WARN)
- **Severity**: Low (no production impact — code is unreachable)
- **Location**: `src/api/keys.ts:80-86` (`handleGetKeys`), `keys.ts:125-131` (`handleGetKeyset`)
- **Description**: The audited file `src/api/keys.ts` constructs `KeysResponse` with only `{id, unit, keys}`, omitting the spec fields `active`, `input_fee_ppk`, and `final_expiry`. A workspace-wide grep for imports of `KeysAPI`, `handleGetKeys`, or `from '…/api/keys'` returns zero external references — only self-references within the file. The production route `/v1/keys` is wired in `src/do/mint-do.ts:732` to `src/mint/router.ts:handleKeys()`, which IS schema-complete (see NUT01-S1).
- **Impact**: None on production traffic. Risk is future confusion if a developer re-wires the legacy handler.
- **Recommendation**: Either delete `src/api/keys.ts` or backfill the three missing fields (`active: true`, `input_fee_ppk`, `final_expiry`) to match the live path. File header already labels it "Legacy context-based handlers kept for compatibility."

### Finding 2: README scalar-reduction formula does not match code (WARN)
- **Severity**: Info (documentation inaccuracy, not a spec violation)
- **Location**: README.md:350 vs `keyset.ts:164`
- **Description**: README states scalar reduction as `(HMAC_output % (n-1)) + 1` (range [1, n−1], never zero). The actual code at `keyset.ts:164` computes `macInt % CURVE_ORDER` (i.e. `% n`, range [0, n−1]) and guards the zero case explicitly at `keyset.ts:168-170` (`if (privateKeyInt === 0n) throw`).
- **Impact**: Functionally equivalent in practice (probability of zero is ~2⁻²⁵⁶; the code rejects it). No security or correctness impact. But the documented formula is inaccurate relative to the implementation.
- **Recommendation**: Update README.md:350 to read `HMAC_output % n` (with zero-rejection guard) to match code.

## Positive Observations
- **Keyset ID derivation** (`keyset.ts:186-205`) supports both NUT-02 V1 (`00` + 7-byte SHA256 prefix) and V2 (`01` + full SHA256) formats, with NUT-01 L40 cross-reference to NUT-02 satisfied.
- **Domain separation** in HMAC context (`keyset.ts:159`: `cashu-mint|v={version}|u={unit}|a={amount}`) ensures per-keyset-per-amount key uniqueness.
- **Private keys never persisted** — derived on demand (`derivePrivateKey` `keyset.ts:289-317`), only public keys stored. Strong security posture.
- **Duplicate-public-key detection** (`validatePublicKeyset` `keyset.ts:457-464`) rejects keysets with colliding public keys.
